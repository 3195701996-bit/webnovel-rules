# webnovel_rules 2.0.2

> 2.0.0/2.0.1 漫画本地书库性能与状态修复候选版本。

## 漫画书库

- 大型本地漫画目录复用严格校验后的下载状态快照，避免每次打开详情都重新遍历所有话与图片。
- 修正冷启动扫描对整份章节清单按章节重复解析造成的二次方退化；现在每部作品只解析一次清单。
- 保留首次严格验证；下载、删除或修复后立即失效缓存并重新核验，防止目录状态滞后。
- Android 本地索引与阅读预载复用已验证结果，减少详情打开和进入阅读器的等待。
- Web 漫画详情不再为缺失的浏览量/更新时间显示空字段。

## 版本与升级

- Android application id：`com.webnovel.mobile`
- 版本：`2.0.2`（`versionCode 157`）
- 最低 Android API：24；目标 API：35；仅发布 arm64-v8a
- 预期从已发布 `2.0.1` 同签名覆盖升级，保留用户应用数据。

## 发布验证

- 候选已完成 clean release 构建、签名与版本校验，并与正式 2.0.1 使用相同签名证书。
- 专用 Android 15 空白模拟器完成 `2.0.1 (156) → 2.0.2 (157)` 同签名覆盖升级；应用内检查确认书架/收藏/阅读进度、部分下载图片、暂停任务及用户书源均保留。
- 5,000 章本地漫画详情 Release 测试通过；最终候选在升级专用模拟器实测接口约 245 ms、Android JSON 解析 5 ms、详情列表约 171 ms、再次打开约 182 ms。五台 API 35 模拟器长目录测试均通过，最慢的存储压力模拟器接口约 1.38 秒。
- Python 全量回归通过；Python 3.11、Python 3.12 与 Android CI 三组 job 全部通过。
- 目标实体手机验收仍需单独完成；模拟器结果不等同于用户设备实测。
- 本候选尚未合并或公开发布，需在发布前再次确认。
