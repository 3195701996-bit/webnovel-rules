# webnovel_rules 3.0.0

Android versionCode 179。此说明随正式身份准备；是否已发布，以 GitHub Release 的实际状态和资产为准，不以本文件存在作为发布证明。

## 漫画书库与追更

- 已缓存入口只展示本地目录；搜索、收藏和阅读历史保留完整在线目录，在线阅读优先使用有效本地图片。部分下载不再挡住新话。
- 章节按真实身份匹配下载与更新，不以列表序号代替话号，不按同名盲目合并。卷在单话前，合并话、分话和历史下载别名使用统一章序。
- 下载默认收藏；可取消收藏而保留本地内容。启动检查收藏更新，按实际读过的章节集合计算未读，重读旧章不会把之后已读章节变回未读。
- 本地管理支持全选、取消全选及精确选择删除；提交前确认，失败可重试且保留选择，不连带删除收藏、阅读历史或未选择图片。
- 下载任务支持筛选、明确失败原因及只补缺页续传；完成状态等待本地索引提交。用户暂停的任务不会因刷新或重启自行恢复。

## 阅读与日常界面

- 点击目录中的章节优先打开所选章节，不被上次续读位置覆盖。长本地目录减少重复扫描，并支持章节查找。
- 漫画阅读默认隐藏上下栏，仅小范围中央点击显示，空闲后自动隐藏；进度条可定位，图片失败可在当前页重试。
- 搜索条件随结果整页滚动；分类按来源独立展示，支持来源实际提供的筛选、排序和分页，迟到请求不会覆盖新选择。
- 小说详情按钮避免窄屏竖排，低频工具默认收起；原文恢复使用独立管理页，旋转后保留选择但要求重新预览。
- 引擎启动失败时仍可进入本地书架、阅读已下载小说和漫画，并使用本地阅读设置；不会把启动中误报为故障。

## 小说清洗与导出

- 增强推广、推书和站点广告识别，区分剧情、作者说明与独立推广章节；提供预览和人工确认，不以激进删文换取“干净”。
- 阅读版导出统一章节标题与边界，处理跨卷重置章号、特殊章节和完整正文去重，避免仅因局部内容相同丢掉整章。
- 新清洗操作保留可校验的原文存档，恢复前检查当前内容；正文已被之后的操作改动时拒绝覆盖。恢复列表跟随真实目录，历史或异常项明确保留在后。
- 元数据修复、导出与恢复均检查数据修订，过期预览需重做；导出在验证失败时不截断目标文件。

## Web 与公共引擎

- Web 同步漫画分类、筛选追更、任务筛选、小说章节查找、清洗预览、阅读版导出、元数据和原文恢复管理。
- 长目录使用整页滚动；长恢复列表在桌面、手机和短屏保留确认与关闭入口，避免操作按钮被挤出视口。
- 下载使用共享源预算、交互图片优先和可取消预取；断网、存储不足等错误保留可恢复状态，不伪报完成。

## 升级与边界

- Android 使用原应用签名覆盖升级，请勿先卸载或清除数据。保留数据升级不等于完整备份；配置备份不包含小说正文、漫画图片或原文存档。
- APK 自带引擎和 Web 资源，但不会替电脑更新正在运行的 Web 服务。电脑请更新到本版源码，在原数据目录、原启动配置下重启；不要另建空数据目录覆盖旧库。
- 源码另提供同一提交的 `.tar.gz`，可用 `tar -xzf webnovel_rules-3.0.0-source.tar.gz` 解压。macOS 旧版 `unzip` 可能在中文文件名处报写入失败，可使用 Finder、`ditto -xk webnovel_rules-3.0.0-source.zip ./` 或 tar 包；不要使用解压失败的半成品启动服务。
- GitHub Release 提供版本下载；本版不宣称提供应用内自动安装或自动升级。
- VPN、源站域名、访问限制及网络质量仍会影响在线功能；不会修改用户 VPN 或安全设置，也不保证所有外部来源始终可用。
- 原文存档只能恢复本版已留存的原文，不能追溯旧版未保存的被删内容。QQ 阅读实测已按用户要求取消，不宣称第三方导入兼容已经实测通过。
- 验收覆盖范围及准确构建证据见 [下一版本验收记录](next-version-acceptance.md)。模拟器、真实源探针和手机保留数据核对各自有范围，不能据此承诺未知缺陷绝对为零。
