# 2.1.0-rc4 候选版

Android code163；候选验证版，不替换2.0.4稳定入口。准备说明不代表已经发布。

## 清理安全修复

- “清理错误缓存”不再仅凭历史失败记录删除已有正常正文；有效正文和下载完成记录保留，纠正过期失败状态。
- 明确章节删除只接受有效整数序号；任意无效或越界项整批拒绝，避免布尔值、小数被转换后误删，也不做部分删除。
- 正常的明确选章删除仍会删除所选内容；清理界面依然要求二次确认。无法证明语义损坏的有效文本保守保留，不擅自删除。

保留rc3全部阅读、更新、长目录和缓存恢复改进。Android和Web共享此引擎修复；电脑Web服务需另行更新源码和重启，安装APK不会自动更新电脑服务。
