# webnovel_rules 2.0.0

> 2.0.0 正式发布说明。

## 漫画阅读与书架

- 漫画目录统一按“整卷在前、单话在后”展示，支持一卷多话与后续单话并存。
- 书架只展示本地已下载目录；从搜索、收藏和阅读历史进入时仍可查看完整在线目录。新话不会被本地目录遮蔽。
- 已下载漫画默认收藏；收藏状态独立于下载状态。收藏页按更新时间排序，封面显示由真实阅读记录计算的未读话数。
- 阅读时优先使用本地图片；在线阅读可在本地内容和在线章节之间连续选择。阅读控件自动隐藏，仅点按较小的中心热区唤出，底部进度滑杆可实时定位。
- 搜索条件与结果随页面自然滚动，长结果和长目录按需加载；卷/章节、下载状态、阅读历史和跨源身份规则补齐回归保护。

## 下载与稳定性

- 修复下载完成但书库仍显示未下载、旧缓存身份匹配失败、书架/详情目录过期等一致性问题。
- 改善漫画图片请求并发、连接复用、交互阅读优先级、预取取消、失败重试与存储不足/进程重启后的恢复。
- 增强备份恢复的原子提交/回滚、旧数据兼容和下载状态校验；错误状态提供可操作的恢复提示。

## 视觉与日常使用

- Web 与 Android 使用统一的暖纸、墨色、陶土与鼠尾草语义色，降低调试面板感。
- 搜索、收藏、书架、下载和阅读的主次层级与手机触控布局重新整理；下载中心使用更清楚的进度、失败原因和恢复操作。

## 发布信息

- Android application id：`com.webnovel.mobile`
- 版本：`2.0.0`（`versionCode 155`）
- 最低 Android API：24；目标 API：35；仅发布 arm64-v8a
- GitHub CI（Python 3.11/3.12、Android）通过；正式 Release APK 同签名核验通过；专用 Android 35 模拟器上的 1.6.4 → 2.0.0 覆盖升级与数据保留断言通过。
