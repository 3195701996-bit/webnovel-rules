# 漫画详情界面规格（用户指定，阶段四实现标准）

基于 venera 实例界面要素，按视觉顺序自上而下：

## 1. 顶部导航栏
- 左侧：返回箭头（返回上一级）
- 右侧：更多选项按钮（三点图标，展开更多操作：复制标题/复制ID/复制URL/浏览器打开）

## 2. 漫画封面与标题区
- 左侧封面图（圆角，点击可放大查看，长按保存）
- 右侧信息：
  - 主标题（可选中复制）：如 "[tlwww个人翻译] [Magisegret] pixie issues 42 [Chinese]"
  - 副标题/来源平台：如 "禁漫天堂"

## 3. 操作按钮区（横向一行）
- **开始阅读**：橙色播放图标 + "开始" → 直接进入阅读
- **点赞**：红色爱心图标 + 数字（如 231 显示点赞数）
- **收藏**：紫色书签图标 + "收藏" → 加入收藏夹
- **评论**：绿色对话气泡图标 + "评" → 进入评论区

## 4. 功能按钮区（横向一行，操作按钮下方）
- **下载**：浅紫色背景 + "下载" → 下载漫画离线阅读
- **继续阅读**：深蓝色背景 + "继续" → 从上次阅读进度继续

## 5. 阅读进度提示
- 时钟图标 + "上次阅读: 第1話 P27"（第X话第X页）

## 6. 漫画信息区（"信息"标题下，标签+内容框布局）
- **作者**：蓝色标签"作者" + 内容框显示作者名
- **标签**：青蓝色标签"标签" + 多个内容框（如 萝莉/3D/中文）
- **浏览量**：粉色标签"浏览量" + 内容框（数字）
- **更新时间**：粉色标签"更新时间" + 内容框（日期）

## 7. 章节列表区
- 章节标题"章节" + 右侧批量下载图标（向下箭头）
- 章节条目纵向排列：如"第1話"（点击进入阅读）

## 设计风格
- 简洁卡片式 + 模块化布局
- 色彩区分功能：操作按钮橙/红/紫/绿；信息标签蓝/青/粉
- 信息层级清晰、操作按钮醒目
- 数据模型字段对应：title/subTitle(来源)/cover/description/tags(标签)/author/views(浏览量)/updateTime/uploadTime/likes(点赞)/chapters(章节列表)/history(上次阅读位置)/downloadStatus

## 实现要求（webnovel_rules 漫画板块）
- 页面路由：/manga/<key>（详情）
- 封面、标题、来源、操作按钮、功能按钮、进度提示、信息区、章节区 全部实现
- 收藏/点赞/评论为可选增强（数据源支持时显示）
- 下载按钮触发整本下载任务（进度显示）
- 继续阅读依据历史记录（阅读器记录 chapter+page）
