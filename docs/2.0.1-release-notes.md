# webnovel_rules 2.0.1

> 2.0.0 稳定性修复版本。

## 漫画阅读

- 修复同一作品从目录重复打开章节时，旧阅读器保存状态覆盖用户刚选择章节的问题。
- 每次明确选择章节都会开启独立阅读会话；应用/页面状态恢复仍保留原会话位置，并兼容旧版导航存档。
- 延续 2.0.0 的本地目录加载提速与章节显式选择优先规则。

## 版本与升级

- Android application id：`com.webnovel.mobile`
- 版本：`2.0.1`（`versionCode 156`）
- 最低 Android API：24；目标 API：35；仅发布 arm64-v8a
- 设计为从已发布 `2.0.0` 同签名覆盖升级，保留用户应用数据。

正式构建的 SHA、签名证书指纹、APK SHA-256、CI 与覆盖升级结果将在完成发布验收后补录。
