## 1. 设计系统缺失

| 优先级 | 问题 | 改法 |
|:---|:---|:---|
| **P0** | 无语义化色彩变量，深色主题硬编码 #1a1a1a 等值 | 建立 CSS 变量体系：`--bg-base` / `--bg-elevated` / `--bg-overlay` 三级表面；`--text-primary`(87%白)/`--text-secondary`(60%白)/`--text-disabled`(38%白)；`--accent` 主色单变量，派生 `--accent-hover`/`--accent-pressed` |
| **P0** | 无字体层级规范，标题/正文/辅助字混用 14-18px 区间 | 定义 6 级字号：`xs=12px`(标注)/`sm=13px`(辅助)/`base=14px`(正文)/`lg=16px`(小标题)/`xl=18px`(章节标题)/`2xl=22px`(页面标题)；行高固定 1.5/1.6/1.75 三档 |
| **P1** | 间距无栅格，margin/padding 任意值 | 4px 基栅格：`space-1=4px` 至 `space-12=48px`，组件内用 8/12/16/24，组件间用 16/24/32 |
| **P1** | 无组件状态规范（禁用/加载/空态/错误） | 统一四类状态样式：禁用=38%透明度+无 hover；加载=skeleton 渐变动画；空态=图标+文案+操作按钮垂直居中；错误=红色图标+重试按钮 |
| **P1** | 无 z-index 层级管理 | 定义：`base=0`/`dropdown=100`/`sticky=200`/`modal-backdrop=300`/`modal=400`/`toast=500`/`fullscreen-reader=600` |
| **P2** | 无动效 token | 定义：`duration-fast=150ms`(按钮反馈)/`duration-base=250ms`(页面切换)/`duration-slow=350ms`(模态框)；缓动：`ease-out` 用于进入，`ease-in` 用于退出 |
| **P2** | 无暗黑/护眼/AMOLED 三主题切换能力 | CSS 变量按主题作用域隔离，通过 `data-theme` 属性切换，预留 `--bg-pure-black` 供 AMOLED |

## 2. 信息架构问题

| 优先级 | 问题 | 改法 |
|:---|:---|:---|
| **P0** | 搜索入口分散（小说/漫画双搜索页），无统一搜索中枢 | 顶部固定搜索栏支持类型切换 Tab，结果页内嵌 segmented control 切换小说/漫画，减少页面层级 |
| **P0** | 书库与下载任务状态割裂，用户无法感知"已下载/仅在线" | 书库列表项统一显示状态徽标：`⬇️`(已下载)/`☁️`(在线)/`⏳`(下载中)，点击已下载项优先离线打开 |
| **P1** | 漫画详情页信息堆叠，未区分"消费决策信息"vs"详情信息" | 首屏固定：封面+标题+作者/状态/评分+继续阅读/下载 CTA；展开后显示：简介+章节列表+相关推荐 |
| **P1** | 章节列表无阅读进度可视化 | 章节项左侧加 4px 竖条进度指示：灰=未读、半高 accent=读至中途、全高 accent=已读完 |
| **P1** | 书源管理 buried 过深，无全局入口 | 设置页置顶书源管理；搜索无结果时引导"切换书源"快捷入口 |
| **P2** | 小说/漫画阅读器设置各自独立，学习成本高 | 统一阅读设置面板：字体/背景/翻页模式/亮度，根据内容类型动态显示相关选项 |

## 3. 交互反馈问题

| 优先级 | 问题 | 改法 |
|:---|:---|:---|
| **P0** | 搜索输入无实时反馈，用户不确定是否触发搜索 | 输入 300ms debounce 后显示 loading spinner 于搜索框内；结果为空时显示"无结果+建议关键词" |
| **P0** | 漫画滚动阅读器无加载占位，图片闪跳 | 图片容器预设 `aspect-ratio` 占位（基于历史平均或预设值），加载中 skeleton 渐变，错误时显示重试按钮覆盖层 |
| **P0** | 翻页/滚动无边界反馈，用户不知是否到末尾 | 到达章节末显示"本章完"浮层+下一章按钮；最后一章显示"已完结"并推荐相似作品 |
| **P1** | 下载任务无进度细分（解析中/下载中/合并中） | 任务项显示三段进度条或步骤指示器：解析→下载→处理，失败步骤标红并可单独重试 |
| **P1** | 长按/右键菜单缺失，与原生 App 预期不符 | 书库项长按：置顶/删除/下载/详情；阅读页长按图片：保存/分享/查看原图 |
| **P1** | 阅读器设置变更无预览反馈 | 设置面板采用 bottom sheet，背景实时透传当前页面，调整即时可见 |
| **P2** | 网络恢复后无自动重试提示 | 全局监听 online 事件，断网时顶部 banner 提示，恢复后自动刷新当前页面并 toast "已恢复连接" |

## 4. 移动端体验改进

| 优先级 | 问题 | 改法 |
|:---|:---|:---|
| **P0** | 漫画阅读器工具栏常驻遮挡内容，且易误触 | 上下滑/单击切换工具栏显隐；工具栏 auto-hide 3s；进度条改为边缘细线+拇指拖拽放大 |
| **P0** | 小说阅读器翻页模式在移动端手势冲突 | 默认滚动模式；点击区域三分：左1/3上一页、中1/3菜单、右1/3下一页；滑动翻页需 ≥40px 位移触发 |
| **P0** | 底部导航/顶部栏占用过多视口 | 滚动向下时导航隐藏（`translateY`），向上时显示；阅读器全屏时全部隐藏，边缘热区呼出 |
| **P1** | 输入框聚焦时页面缩放（iOS Safari 默认行为） | 所有输入框 `font-size: 16px`，禁止缩放；搜索框聚焦时展开全屏覆盖层，避免布局偏移 |
| **P1** | 漫画网格卡片过小，拇指难以精准点击 | 网格列数：≤360px 2列、361-480px 3列、>480px 4列；卡片最小点击热区 88×88px（含间距） |
| **P1** | 无 PWA/Add to Home Screen 优化 | 提供 `manifest.json` + 主题色/图标；离线时显示缓存内容提示；支持系统返回键行为定义 |
| **P1** | 章节列表长列表无虚拟滚动或分页加载 | >100 章时分段加载，滚动至底部加载下一批；或虚拟滚动固定高度项，DOM 回收 |
| **P2** | 无系统级媒体控制集成 | 小说阅读器支持后台音频播放时，接入 Media Session API 显示章节信息+播放控制 |
| **P2** | 横屏体验未定义 | 漫画阅读器横屏强制双页模式（平板）或单页放大（手机）；小说阅读器横屏保持单栏，增大边距 |

## 附：关键 CSS 变量骨架（可直接用）

```css
:root {
  /* 色彩 */
  --bg-base: #0f0f0f;
  --bg-elevated: #1a1a1a;
  --bg-overlay: #262626;
  --text-primary: rgba(255,255,255,0.87);
  --text-secondary: rgba(255,255,255,0.60);
  --text-disabled: rgba(255,255,255,0.38);
  --accent: #6366f1;
  --accent-hover: #818cf8;
  --accent-pressed: #4f46e5;
  
  /* 间距 */
  --space-unit: 4px;
  
  /* 层级 */
  --z-dropdown: 100;
  --z-sticky: 200;
  --z-modal-backdrop: 300;
  --z-modal: 400;
  --z-toast: 500;
  --z-reader-fullscreen: 600;
  
  /* 动效 */
  --duration-fast: 150ms;
  --duration-base: 250ms;
}
```
