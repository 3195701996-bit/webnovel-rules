# webnovel_rules 2.0.4

Android 版本号 2.0.4，versionCode 159。

## 修复

- 拷贝漫画已缓存域名连接失败时，在原有请求时间预算内尝试其他域名；不再把单个域名不可达直接判定为全部域名不可达。搜索、分类、目录和章节图片链接获取共用此修复，Android 与 Web 均受益。
- 仍不重复请求已失败域名，不在 HTTP 403 或挑战页面出现时切换域名继续请求，不增加 APP 通道回落。

## 说明

手机规则模式曾失败、全局模式可用，随后规则模式自行恢复。当前没有证据证明该暂时异常由应用升级引起；本版本不修改 VPN、DNS、代理规则，也不宣称修复了该未复现异常。

## 验证范围

专项回归覆盖缓存域名连接失败后的切换、全部域名失败、请求预算、明确拦截时停止、分类解析与分页。离线故障注入验证不等同于物理手机 VPN 规则模式验收。
