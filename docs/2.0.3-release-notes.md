# webnovel_rules 2.0.3

Android 版本号 2.0.3，versionCode 158。修复 2.0.2 的收藏、章节排序、探索与手机详情布局问题。

## 本次修复

- 修正原生漫画详情的取消收藏接口；取消后收藏状态持久保存，本地下载不受影响。
- 支持“第01-02话”等合并章节按起始话号排序；在线目录与旧本地目录使用相同规则，整卷优先的阅读顺序保留。
- 小说详情四项次要操作改为两列布局，避免按钮文字逐字换行；漫画“下载 / 补齐未完成内容”简化为“补齐下载”。
- 探索清单按书源身份去重，修复重复“精华书阁”导致的列表闪退；Android 解析层同时去重以兼容旧响应。
- 探索源发现不再等待远程分类网络请求；禁漫分类后台刷新，先展示排行与已有分类。
- Android 源选择、全源搜索与自检列表移除依赖浏览器的“拷贝漫画（网页版）”；旧下载、收藏与阅读历史仍保留跨通道身份兼容。
- 拷贝漫画新增官网分类浏览：70 个入口（2 种排序、68 个题材），读取官网实际分类清单与分页漫画数据，不混入推荐卡片。
- 漫画分类页采用横向源切换、分组标题与自动换行分类按钮；分类区域随页面滚动，沿用应用深浅色主题。
- 单源入口只展示所选源，分类采用同样的分组按钮；诊断与图片缓存修复收进“源信息”，返回不会逐个回放切源历史。
- Web 漫画工作区同步新增分类入口：源选择、分组分类、分页加载、返回分类、详情返回后恢复结果；支持窄屏按钮换行与分页去重、失败重试不跳页。
- 拷贝分类支持地区、连载/完结/短篇筛选和时间/热度双向排序，切换条件重置页码，展示官网总页数；桌面普通 HTTP 不可达时复用搜索的浏览器通道，并加入官网当前域名。
- 修复旧完整目录缓存命中时保留错误章节顺序的问题，重新排序后按章节身份计算续读位置，无需删除本地漫画。

## 验证

- Android Release 回归验证取消收藏持久保存、探索列表滚动与小说分类导航、手机详情按钮宽高。
- APK 内实测拷贝漫画“爱情”分类前两页各 30 部、作品不重复，“加载更多”后显示 60 部和第 2 页；确认网页版源不在手机源列表中。
- 5,000 章本地目录性能回归通过：模拟器接口 267 ms、JSON 解析 4 ms、列表显示 180 ms、复开 128 ms。
- Python 回归、Android JVM 测试、Web JavaScript 回归、客户端接口契约及 20 个真实 HTTP 冒烟检查纳入发布验证。
- 拷贝漫画联网验证使用测试代理；用户设备上的可达性取决于当地网络与应用的代理设置。
