## 相比rc4

- 修复浅色窗口背景下状态栏图标不可读；初始页、小说夜间正文外的浅色顶底栏均保持深色系统图标。API24／25保留兼容的深色导航栏。

保留rc4的清理安全修复和此前阅读、更新、目录、待补队列功能。电脑Web服务需要单独更新源码并重启，安装APK不会自动更新电脑Web。
