# 2.1.0-rc3 候选版

Android versionCode 162。这是候选验证版本，不代表全部项目验收完成；准备此说明不代表已经发布。

## 相比 rc2 新增修复

- Web 漫画阅读：修复进度定位的小数像素误差、快速跳页的旧回调干扰、键盘操作范围、双页末屏、翻页热区及窗口宽度变化后的页码保持。本地目录选章保留章节 ID 与本地模式。
- 小说缓存：书库、详情、更新检测和续传统一核对真实正文，不再因超过5000章而使用旧完成记录。非法 UTF-8、纯空白、空文件不算下载成功；已恢复正文不因旧失败记录重复下载。
- 小说阅读：异常进度请求不会覆盖有效位置；修复下载百分比显示；用户展开、搜索或滚动目录后，迟到的历史进度不再抢走当前位置。
- 拷贝目录：备用通道分页失败／异常空页／重复或缺失章节 ID 不再返回成功的半份目录。网页完整目录仅按同一 ID 去重，不按标题合并。

## 保留 rc2 功能

本地内容全选管理、更新章节预览、目录差异提醒、章节查找与核对信息、运行中追加待补队列、本地与在线目录分离均保留。Android 和 Web 使用同一引擎；Web 需要更新运行服务，安装 APK 不会自动更新电脑上的 Web 服务。

## 已有证据与未完成门槛

已有隔离真实旧书库 Web 阅读／更新测试、API35 原生阅读与长目录测试，以及磁盘满、重启断网后补缺页的故障注入回归。准确提交的最终全量、正式签名及覆盖升级证据需在构建后补验，不能沿用旧提交结果。

手机《社長與酒與星》两条第41话尚缺原始 ID／内容核对，不宣称根因已解决；不会自动合并或删除历史同名章。vivo Android16 真机与系统存储界面体验仍未验收，不宣称全面超过所有同类产品。
