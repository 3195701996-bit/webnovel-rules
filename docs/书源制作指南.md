# legado 书源制作指南（webnovel_rules 兼容子集）

## 书源 JSON 结构

```json
{
  "bookSourceName": "站点名（显示用）",
  "bookSourceUrl": "https://www.example.com",
  "bookSourceType": 0,
  "bookSourceGroup": "分组名",
  "enabled": true,
  "searchUrl": "/search?keyword={{key}}",          // 搜索（{{key}} 关键词，{{page}} 页码）
  "ruleSearch": {                                   // 搜索结果解析
    "bookList": "div.list li",                      // 书籍列表选择器
    "name": "a.title@text",                         // 书名（在列表项上）
    "author": ".author@text",                       // 作者
    "bookUrl": "a@href",                            // 书籍链接
    "intro": ".intro@text", "kind": "", "coverUrl": ""
  },
  "ruleBookInfo": {                                 // 书籍详情页
    "name": ".book-name@text",
    "author": ".author@text##作者[:：]\\s*",         // ##正则##替换 清洗
    "intro": ".intro@text",
    "tocUrl": "{{$.}}"                              // 目录页 URL（默认=详情页）
  },
  "ruleToc": {                                      // 目录
    "chapterList": "ul.chapters li",                // 章节列表
    "chapterName": "a@text",
    "chapterUrl": "a@href",
    "nextTocUrl": ""                                // 目录分页链接（可选）
  },
  "ruleContent": {                                  // 正文
    "content": "#chaptercontent@text",
    "nextContentUrl": "",                           // 章节分页（可选）
    "replaceRegex": "##广告文本|（第\\d+/\\d+页）"     // ##移除模式1|模式2
  },
  "tocSort": "url",                                 // 可选：按 URL 数字排序目录
  "header": "{\"User-Agent\": \"...\"}"             // 可选：请求头
}
```

## 规则语法速查

| 规则 | 说明 | 示例 |
|---|---|---|
| CSS 选择器（默认） | `tag.class#id [attr=val]` | `div.list ul li a` |
| 显式 CSS | `@css:选择器` 或 `@jsoup:选择器` | `@css:.item` |
| JSONPath | `@json:路径` 或 `$.路径` | `$.data.list[*].name` |
| 正则 | `@正则:pattern` | `@正则:var bid="(\d+)"` |
| 元素操作 | `选择器@text/@href/@src/@html/@content/@attr:x` | `a@href` |
| 去首 N 个 | `选择器!N` | `dl@dd!0`（去掉第一个 dd） |
| 结果清洗 | `##正则##替换` 或 `##移除模式1\|模式2` | `##作者[:：]\s*` |
| 多规则 | `规则1\|\|规则2`（依次尝试） | `.a@text\|\|.b@text` |
| 链式 | `规则1@@规则2`（前段结果上继续） | `@css:li@@a@text` |
| 模板 | `{{key}}/{{page}}/{{searchKey}}/{{$.x}}` | `/search?q={{key}}&p={{page}}` |

## 制作步骤

1. **分析搜索**：浏览器打开搜索页（如 `/search?keyword=测试`），开发者工具查看结果 HTML 结构
2. **确定选择器**：用 CSS 选择器定位书籍列表项、书名、作者、链接
3. **分析详情页**：书名/作者/简介/目录位置；`tocUrl` 通常是详情页本身
4. **分析目录页**：章节列表选择器 + 章节名/链接；分页目录用 `nextTocUrl`
5. **分析正文页**：正文容器 + 广告/导航文本清除（`replaceRegex`）
6. **验证**：用系统"导入书源"功能（自动校验搜索）或 `engine.source_mgr.validate_source`

## 常见陷阱

- 作者/简介字段常带前缀标签：用 `##作者[:：]` 清洗
- 正文容器内混入导航/广告：`replaceRegex` 逐条移除
- 章节分页：`nextContentUrl` 取"下一页"链接（正则提取）
- 目录含"最新章节预览"等重复区：`tocSort:"url"` 按 URL 数字排序
- 站点要求特定 UA：书源 `header` 字段
- 繁体/编码：fetcher 自动嗅探 charset
