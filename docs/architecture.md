# 架构与数据边界

[文档导航](README.md)

```text
Web 浏览器 ── Flask API ── 公共 Python 引擎 ── 书源 / 漫画来源
                             ▲
Android Compose ── 本机回环 API┘  （Chaquopy 内嵌，不依赖电脑）
```

两种形态使用同一套源码和数据契约，各自拥有独立运行实例。电脑与独立 APK 不会自动同步数据。

| 目录 | 职责 |
|---|---|
| [app.py](../app.py) | Web 入口、应用装配与生命周期 |
| [engine/](../engine/) | 规则引擎、小说/漫画适配器、网络预算、下载及正文处理 |
| [server/](../server/) | API、持久状态、运行时与 Android 引擎入口 |
| [templates/](../templates/) / [static/](../static/) | Web 模板、样式与交互 |
| [android/](../android/) | Compose 原生界面、回环客户端与构建配置 |
| [sources/](../sources/) | 受版本管理的书源种子 |
| [tests/](../tests/) | Python、JS 与共享契约夹具；原生测试另在 android/app/src/ |

## Android 的源码来源

Gradle 在构建期从仓库根目录生成 Python/Web 快照和书源种子，不维护第二份手工镜像。请修改根目录权威源码或原生界面，不编辑 `android/app/build/` 产物。旧 `android_app/` 目录不是当前项目入口。

## 内容与阅读状态

- 已缓存漫画入口只使用本地目录；搜索、收藏和历史详情保留完整在线目录，在线阅读优先复用有效本地图片。
- 作品/章节身份与目录显示序号分离，卷优先于单话；更新与下载不能仅靠标题或序号匹配。
- 阅读进度与下载任务进度是不同状态。收藏未读数根据实际已读章节集合计算，不用“最大读到话数”代替。
- 配置/进度备份不包含正文、图片或清洗原文存档；保留数据安装也不等于完整备份。

## 本地数据

Web 默认数据目录为仓库下 `data/`；可用 `WR_DATA_DIR` 指定原有数据目录，`WR_SOURCES_DIR` 指定书源目录。Android 使用应用私有目录。不要把手机私有目录或电脑用户数据提交到 Git。

Web 默认仅监听 `127.0.0.1`。远程访问需单独考虑鉴权和部署配置；本仓库不提供默认公开托管服务。
