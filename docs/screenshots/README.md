# 展示截图

[项目首页](../../README.md) · [文档导航](../README.md)

截图为 **3.0.0 已实现界面**，使用虚构书目“星海航行手记”等隔离演示数据，不含真实用户内容、账号、代理、阅读记录或设备标识。它们不是设计稿，也不代表外部源实时返回的数据。

| 文件 | 环境与内容 |
|---|---|
| [Android 浏览入口](v3-android-browse.png) | API36 专用模拟器；已发布3.0.0 APK；真实 BrowseScreen |
| [Android 小说详情](v3-android-novel.png) | 同一APK真实导航/本机引擎与演示缓存；目录120章、已下载80章 |
| [Web 桌面详情](v3-web-desktop.png) | Chrome / Playwright，1440×1000；真实隔离服务和演示缓存 |
| [Web 手机详情](v3-web-mobile.png) | 同一服务，390×844；章节查找、下载状态与整页布局 |

Android 使用显式开启的 DocumentationGalleryTest，先检查qemu身份；只在专用模拟器创建UUID演示书目，结束恢复并清理，不写用户真实书库，禁止在物理手机运行。通过真实导航打开页面后捕获已渲染的Compose根节点，避免把过渡帧当展示。Web 使用临时数据目录和任务自建服务，验证页面身份、控制台、章节精确查找及取消筛选后截图；没有部署用户电脑服务。

图片不修改业务界面，不使用真实漫画封面或用户截图。Android/网页状态条及界面数据是演示环境，不能据此推断真实性能、完整下载覆盖或全部来源可用性。
